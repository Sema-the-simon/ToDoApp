# ToDoApp

## Описание проекта

ToDoApp — это приложение для создания, редактирования и хранения заметок о делах, разработанное в рамках курса "Школа Мобильной Разработки". Основная цель проекта — закрепить полученные знания и навыки в области мобильной разработки на платформе Android, а также создать портфолио, отражающее прогресс и достижения в обучении.

### Основные возможности:
- Создание, редактирование, удаление и хранение задач (CRUD-операции).
- Поддержка офлайн-режима с синхронизацией данных при наличии подключения к сети.
- Поддержка темной и светлой темы.
- Настроенный Accessability, для работы приложения в режимие "Ограниченные возможности"
- интеграция с **DivKit** для создания экрана "О приложении".

## Используемые технологии

Проект разработан с использованием современных технологий и инструментов для Android:

- **Kotlin**: основной язык разработки.
- **Jetpack Compose**: декларативный фреймворк для создания пользовательского интерфейса.
- **Ktor**: клиентская библиотека для работы с сетью.
- **Hilt**: DI (Dependency Injection) для управления зависимостями.
- **Room**: библиотека для локального хранения данных.
- **Coroutines**: для асинхронного программирования.
